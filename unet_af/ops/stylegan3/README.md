# StyleGAN3 ops

This directory vendors a subset of the custom PyTorch ops (`bias_act`,
`filtered_lrelu`, `upfirdn2d`), `conv2d_gradfix`, `misc`, `custom_ops`, and
`dnnlib` modules from NVIDIA's official StyleGAN3 repository:

https://github.com/NVlabs/stylegan3
